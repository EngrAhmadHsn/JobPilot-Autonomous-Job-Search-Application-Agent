# Autonomous AI Job Application Agent

This project is the foundation for an autonomous AI-driven job application system.

## Current status

- Phase 0: environment and configuration audit
- Phase 1: project foundation scaffold

## Quick start

1. Create and activate the project virtual environment.
2. Install dependencies from `pyproject.toml`.
3. Start the API with:

```bash
uvicorn src.main:app --reload
```

4. Check the health endpoint:

```bash
http://localhost:8000/api/health
```
