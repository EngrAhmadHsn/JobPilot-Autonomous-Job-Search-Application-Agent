## Context
On `/app/matches` (Discover), the desktop layout locks both columns to the viewport, putting the selected job in a scroll box and giving the results a competing scrollbar. The inline detail currently shows the match explanation; the full description is only visible on the separate listing page. I’ll make Discover read like a page: the whole description in the right column, with a results list that stays within reach on the left.

## Implementation
1. **Use native sticky scrolling on desktop.** In `frontend/src/screens/matches-screen.tsx`, remove the fixed viewport height, clipping, and right-side scroll wrappers. Let the detail set the grid’s height and scroll with the document. Keep the current split ratio and pin the results column below the desktop header. Only the rows and “Show more” scroll inside that column; the count stays visible. Use a thin, muted native thumb with no heavy track, room for focus rings, and default system scrollbar styling in forced-colors mode. Very short windows can use normal page flow rather than squeezing the list. No scroll hijacking, animation library, or moving parallax layers. Make the intended desktop header stick in `frontend/src/components/layout/app-shell.tsx` so it and the results column don’t overlap.
2. **Show the full stored description in place.** In `frontend/src/screens/discover/match-detail.tsx`, use the existing `PlainText` component and the standalone `JobDetailScreen`’s wrapping and missing-description treatment. Keep the fit explanation and existing actions. No new API request or change to the standalone listing route is needed.
3. **Keep navigation predictable.** Preserve `ResultsList` keyboard navigation, desktop first-match selection, explicit `?job=` links, and all current filter query params. Selecting another result should bring its heading back into view when needed without resetting the list. On mobile, open to results unless a job is explicitly linked; selecting a row opens the full detail in page flow, and “Back to results” returns focus to the row instead of reopening the top match.
